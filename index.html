rawmakase-zh · pacman 仓库

RAWmakase 中文版 0.4.1 的二进制包，供 Arch Linux 的 pacman 直接安装。签名密钥：F2EBB07B9579715A

导入签名公钥（只需一次）

sudo pacman-key --add - <(curl -fsSL https://rmyou.github.io/rawmakase-zh/rawmakase-zh.asc)
sudo pacman-key --lsign-key F2EBB07B9579715A

添加仓库

[rawmakase-zh]
SigLevel = Required
Server = https://rmyou.github.io/rawmakase-zh

写进 /etc/pacman.conf 末尾，然后 sudo pacman -Syu rawmakase-zh。
